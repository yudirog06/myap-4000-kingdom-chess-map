# ♟️ MYAP-4000: Kingdom Chess Map

**⚠️ Prototyped in Excel, built for the Web. ⚠️**

This is a fully playable chess variant where the AI is driven by a **±10 Reach Map** for territory control and collision detection. The core logic was originally designed and calculated using raw, complex **Excel array formulas** (SUMPRODUCT, CODE, ABS) before being ported into a playable HTML5/JavaScript engine.

## ⚙️ How It Works

- **Asymmetric Terrain:** White (Highlands) vs. Black (Lowlands) with different tactical advantages.
- **Two AI Modes:** "Mixed" (classic chess + map) and "Pure MYAP" (ruthless map domination).
- **Field Report:** Every move is narrated as a military log.
- **Collision Detection:** Pieces stop exactly when blocked, ported from the original Excel `SUMPRODUCT` logic.

## 🛠️ Tech Stack

- **Prototype:** Microsoft Excel (Array Formulas, No VBA)
- **Web Engine:** HTML5, CSS3, vanilla JavaScript
